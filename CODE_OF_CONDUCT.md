# Community conduct

Treat participants with respect regardless of background, experience or identity. Give constructive feedback about code and ideas. Do not harass, threaten, discriminate, publish private information, or engage in unwanted personal contact.

Maintainers may remove inappropriate content, pause discussions or restrict participation to protect the community. Report conduct concerns privately to repository maintainers; if no private contact is published, request one without posting sensitive details publicly. Maintainers should acknowledge concerns, protect confidentiality where possible and explain moderation decisions to affected participants.

This policy applies in project repositories, discussions and project-sponsored spaces. Technical disagreement is welcome; personal attacks are not.
