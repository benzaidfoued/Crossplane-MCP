# Crossplane Compass v0.1.0

Initial release: 24 evidence-based MCP tools for discovering Crossplane APIs, diagnosing resource graphs and preparing reviewed GitOps changes.

Includes stdio and authenticated Streamable HTTP, exact CRD discovery, v1/v2 tracing, owner UID checks, package health, catalog and schema inspection, scaffolding/validation/diffs, external-name lookup, adoption/migration checks, a Helm chart, contributor documentation and gated release automation.

Security defaults: no persistent mutation tools, no Kubernetes Secret reads, explicit API-group permissions, non-root container and authenticated HTTP. Server-side dry-run is optional and requires additional patch RBAC.

See SECURITY.md for data-redaction and shared-identity limitations, and docs/validation.md for locally executed validation versus downstream integration gates. This initial release does not claim cloud identity verification, full admission equivalence, core-resource traversal, zero defects or production certification.
